This repository contains solutions to technical interview preparation challenges completed as part of the **ALX Software Engineering Program**. The problems focus on core algorithmic patterns, dynamic programming, recursive backtracking, bitwise manipulation, in-place matrix operations, graph traversal, and asynchronous API integration.

## Requirements & Environment

- **Python Scripts**:
  - Python version: `3.8.x`+ (Ubuntu 20.04 LTS)
  - Style guide: PEP 8 / `pycodestyle` (version 2.8.*)
  - All files are executable (`chmod +x *.py`) and begin with `#!/usr/bin/python3`
- **JavaScript Scripts**:
  - Node.js version: `14.x`+ (Ubuntu 20.04 LTS)
  - Style guide: Semistandard (`semistandard`)
  - All files are executable (`chmod +x *.js`) and begin with `#!/usr/bin/node`
